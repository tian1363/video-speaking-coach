# 一分钟上手｜Video Speaking Coach

1. 在桌面 Chrome 打开一段 YouTube 视频，观看后点击插件图标。
2. 在侧边栏写下人物、事件、观点或不懂的词。
3. 第 1 轮只看自己写的关键词，用语音把它们串成英文；第 2 轮按“主题 → 重点 → 例子”重讲；第 3 轮尽量不看笔记，独立表达并加入看法。
4. 每轮可用麦克风输入或直接打字。语音首次使用时，按页面说明主动授权；提交前检查转写。
5. 需要即时翻译时输入单词。想获得个性化建议，在“AI 教练设置”中选择服务商；若不懂 API Key，点击“前往官网获取 API Key”，创建后返回插件粘贴。
6. 三轮结束后回看原话与建议，点击“下载 Markdown”保存记录。可在 Notion 手动导入文件，或放入 Obsidian。

**你可以随时离开视频页。**侧边栏会保留最近一次练习，并提供“返回视频”。

**当前边界：**基础查词可能受公共服务限流；AI 建议使用用户自己的付费或有额度的 API；Notion 没有一键同步；插件不会自动总结视频内容。

完整说明见 [使用教程](../USER_GUIDE.md)。
