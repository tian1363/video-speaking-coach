# 产品简介｜Video Speaking Coach

**一句话：**不知道怎样练英语口语？打开一段感兴趣的 YouTube 视频，跟着插件完成“观看 → 记关键词 → 自己复述 → 获取建议 → 再练习 → 收藏记录”。

## 为什么做

不少人想练口语，却不知道每天具体要做什么；也有人看了很多英语视频，真正开口时仍难以讲清自己的理解。Video Speaking Coach 把常见的复述、回顾和反馈练习整理成一套能在浏览器里直接执行的流程。用户选择自己感兴趣的内容，插件负责提示下一步、留下原话，并帮助发现下一轮可以改进的地方。

## 适合谁

适合已经会找感兴趣的英语视频，却缺少固定开口练习方法的人。用户自己观看和理解视频，插件提供练习节奏、记录与反馈。

## 一次练习如何完成

1. 在 YouTube 看完自己选的视频，在侧边栏记下关键词。
2. 第 1 轮自由复述；第 2 轮按主题、重点、例子讲清楚；第 3 轮脱离笔记，加入个人观点。
3. 每轮使用浏览器语音识别或键盘输入；提交前可修改英文转写。
4. 随时查词。基础翻译无需 API Key；语境解释、口语建议和问答需要自行配置 OpenAI 或阿里云百炼。
5. 查看原话和建议，按建议再讲一次。完成三轮后下载 Markdown，或将记录送入 Obsidian；Notion 通过手动导入 Markdown 收藏。

## 产品边界

插件不下载 YouTube 视频，不自动读取整段字幕，也不替用户生成视频复述。AI 建议依据用户记录的标题、关键词、复述与问题；因此用户仍需自己判断内容是否准确。当前版本提供文字建议，**尚无量化 AI 评分或发音评分**。原始音频不由扩展保存。API 服务商可能按使用量收费。

## 发布定位

Chrome 桌面端开源扩展。主张是**把口语练习方法变成方便执行的流程**：从一次视频出发，反复表达，并留下可回顾的练习记录。

## 费用与使用自由度

插件不要求购买统一的口语课套餐。练习流程与基础查词不需要 AI Key；需要个性化建议时，用户可选择当前支持的 OpenAI 或阿里云百炼普通 API Key，由所选服务商按实际用量计费。符合服务商条件的免费额度可以抵扣调用费用；额度、地区、期限和模型由服务商决定。想练时打开 YouTube 和侧边栏即可开始，不需预约课程。

当前版本只接入 OpenAI 和阿里云百炼普通 API，**并非任意服务商的 API Key 都能直接使用**。其他兼容服务商可列入后续版本计划，发布文案不要写“哪家都可以”或“永久免费”。
