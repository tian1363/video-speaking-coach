## 单一用途

帮助用户围绕自己观看的 YouTube 视频，按“关键词 → 三轮英语复述 → 反馈 → 保存记录”的流程练习口语表达。

## 权限理由

| 权限或站点 | 后台可填写的理由 |
| --- | --- |
| `sidePanel` | 在视频旁显示关键词、复述、反馈和历史记录。 |
| `storage` | 在本机保存练习记录，并在当前 Chrome 会话保存用户自己的 API Key。 |
| YouTube、`youtu.be` 站点 | 识别普通视频、Shorts 与直播回放链接，并在切换标签页后更新当前练习视频。 |
| OpenAI API | 用户选择 OpenAI 并主动请求建议、语境查词或问答时调用其 API。 |
| 阿里云百炼 API 站点 | 用户选择百炼及所属地域并主动请求上述 AI 功能时调用对应地域的 API。 |
| MyMemory 翻译 API | 用户主动输入单词或短语进行基础翻译时发送该查询词。 |

扩展代码没有从远程加载并执行 JavaScript；AI 与翻译接口只返回数据。不要把“使用 AI API”误填为“执行远程代码”。

## 隐私表单核对

向后台如实披露：视频地址和标题、用户输入的关键词与复述、问题和查词内容、AI 反馈，以及作为认证信息的用户 API Key。练习记录存在扩展本地；主动调用功能时，相关内容会直接发给所选服务商。语音识别由浏览器提供，扩展不保存原始音频。扩展不运行行为分析、不出售数据、不投放个性化广告。各分类名称以后台实际选项为准，核对 [公开隐私政策](../PRIVACY_POLICY.md) 后提交。

## 给审核员的测试说明

1. 在桌面版 Chrome 打开任意公开的 YouTube 视频页，点击扩展图标，侧边栏应出现该视频。
2. 看完后输入关键词，在第一轮文本框输入英文并提交。无需 API Key 即可完成三轮及使用基础翻译；建议区会显示固定练习提示。
3. 在“AI 教练设置”选择 OpenAI 或阿里云百炼，填入相应地域可用的普通 API Key 和模型后，可测试个性化建议。若审核需要测试凭证，请只通过开发者后台的私有测试说明提供短期凭证，不要写进仓库、截图或 ZIP。
4. 完成三轮后可下载 Markdown、重新练习并查看旧尝试；删除记录按钮可清除当前视频的本地数据。
5. 麦克风需由用户主动点击“开始语音输入”并授权；也可直接打字完成全部流程。
