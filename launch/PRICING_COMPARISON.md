# 费用与竞品对比笔记

**核对日期：2026-09-26。**这是宣传策划时的参考计算，不是插件内的实时计费器。发布前需重新核对服务商和竞品页面。

## 先界定产品

- 当前插件支持用户自带 **OpenAI** 或 **阿里云百炼普通 API Key**，不是“任意 API Key”。不同厂商的鉴权、请求格式、浏览器跨域规则和使用条款不同；更多服务商要逐家接入与测试。
- 观看、记关键词、三轮复述、保存记录可不配置 AI Key；基础查词通过公共翻译服务提供，可能限流。
- 个性化 AI 建议需要服务商 API。百炼的[新人免费额度](https://help.aliyun.com/zh/model-studio/new-free-quota)仅适用于符合条件的北京地域模型，通常有 90 天期限；已认证用户额度用尽后可能自动转按量计费。应在控制台查看本人实际剩余额度，可开启“免费额度用完即停”。
- “随时可用”的准确意思是**不需预约真人课程，想练时可打开插件**。实际使用仍取决于网络、YouTube、浏览器语音识别和服务商可用性。

## 一次三轮练习的示例模型成本

假设三轮共调用 AI 三次、合计 **6,000 输入 tokens + 1,200 输出 tokens**，没有额外问答、查词或缓存优惠。此 token 量只是估算，尚未由真实使用数据验证；更长的视频标题、复述或回答会改变费用。

| 模型与地区 | 官方公开单价 | 按上述假设的模型费 |
| --- | --- | --- |
| OpenAI `gpt-4.1-mini` | 输入 $0.40 / 百万 tokens；输出 $1.60 / 百万 tokens | **约 $0.00432 / 次三轮练习** |
| 百炼 `qwen-plus` 北京，按非思考模式价 | 输入 ¥0.80 / 百万 tokens；输出 ¥2.00 / 百万 tokens | **约 ¥0.0072 / 次三轮练习** |

公式：`6,000 ÷ 1,000,000 × 输入单价 + 1,200 ÷ 1,000,000 × 输出单价`。百炼若进入思考模式、使用其他地区或其他模型，价格可能不同。实际账单以服务商为准。来源：[OpenAI GPT-4.1 mini 模型价格](https://developers.openai.com/api/docs/models/gpt-4.1-mini)、[百炼 qwen-plus 模型价格](https://help.aliyun.com/zh/model-studio/qwen-plus)。

## 与真人课和 AI 口语产品相比

| 参照 | 公开价格示例 | 换算说明 |
| --- | --- | --- |
| [Preply 在线英语私教](https://preply.com/en/online/english-tutors/adults) | 页面写明平均约 **$16 / 小时**，具体教师价格不同 | 单纯以模型账单计算，$16 ÷ $0.00432 ≈ **3,700 次**上述三轮练习。这里比较的是 API 调用费与真人课价格，**不代表 3,700 次自练等于 1 小时真人教学**。 |
| [ELSA Speak Premium](https://elsaspeak.com/payment/stripe/checkout?discount_code=PROSUBEN&membership=one_year_credit_premium) | 查询到的结账页面显示 **$159.99 / 年**，地区、渠道、促销可能不同 | 单纯以模型账单计算，$159.99 ÷ $0.00432 ≈ **37,000 次**上述三轮练习。ELSA 包含发音分析、课程等本插件没有的服务，不能据此比较学习效果。 |

以百炼北京的上述非思考模式示例计算，**¥1 模型调用费约对应 139 次三轮练习**。这是理论换算，不包含超出假设的额外 AI 请求，也不是服务商保证的练习次数。

## 对外建议怎么说

> 不用预约课程，想练时就打开视频和侧边栏。基础练习可以直接开始；需要 AI 建议时，用自己的 OpenAI 或百炼普通 API Key，按服务商实际用量付费。符合条件的免费额度也可以使用。

价格对比适合放在注明来源、日期和假设的长文或 FAQ 中。商店短描述建议突出**流程、自主选择与按量使用**，不使用“上万节免费课”“比真人老师便宜几千倍”等可能让人误解为教学效果等价的说法。
