## 一句话介绍

不知道怎么练口语？看一个喜欢的视频，跟着步骤讲出来。

## 新增卖点：练习自主，费用透明

**短句：**想练就练，不用预约；AI 教练用自己的 Key，按实际用量走。

**展开说：**看视频、记关键词和三轮复述都能直接开始。需要 AI 建议时，选择当前支持的 OpenAI 或阿里云百炼普通 API，填入自己的密钥。符合条件的账号可使用服务商提供的免费额度；没有额度时，调用费用由所选服务商按用量收取。你决定什么时候练、练哪段视频、是否开启 AI。

**避免使用的说法：**“任何 API Key 都能用”“永久免费 AI”“比一节真人课便宜上千倍”“24 小时绝对可用”。现版本只接入两家服务商；价格和额度会变化，服务可用性取决于网络、YouTube、浏览器及模型服务商。详细价格估算见 [费用对比笔记](PRICING_COMPARISON.md)。

## 社交平台短帖

很多人想练口语，难点是每天不知道具体怎么练。我把“先输入，再主动输出”的练习方法做成了一个浏览器插件。看完自己感兴趣的 YouTube 视频，先记几个关键词；第一次对着麦克风，只看这些词，用英文把它们串成自己的理解。第二次把逻辑讲清楚，第三次尽量不看笔记、说出自己的观点。插件保留每轮原话；需要个性化建议时，可以连接自己选择的 OpenAI 或百炼普通 API。想练就打开侧边栏，不用预约；练完把记录导出为 Markdown，收藏进自己的笔记系统。

这是一套可以马上动手的练习流程，适合视频看了不少，却一直缺少开口练习方法的人。

## GitHub 发布介绍

**Video Speaking Coach** 是一个开源 Chrome 扩展，帮想练口语却不知道怎样开始的人，把 YouTube 视频变成可执行的三轮复述练习：看视频、记关键词、自己说、看建议、再练习、收藏记录。它保留关键词、三轮原话、词汇和建议，支持浏览器语音识别、免 Key 基础查词、自带密钥的 AI 教练，以及 Markdown 导出。

它的目标是让学习者自己组织并说清内容。插件不会自动替用户看视频或生成整篇复述；目前反馈以文字建议呈现，没有量化打分。欢迎试用、反馈练习流程和贡献代码。

项目地址：[github.com/tian1363/video-speaking-coach](https://github.com/tian1363/video-speaking-coach)。如果你认同这套练习方法，欢迎 Star 仓库并分享给朋友。

## 30 秒演示视频脚本

| 时间 | 画面 | 旁白/字幕 |
| --- | --- | --- |
| 0–5 秒 | YouTube 视频与插件侧边栏并排 | “想练口语，却不知道从哪里开始？” |
| 5–10 秒 | 输入 3 个关键词 | “先记住你自己的印象。” |
| 10–18 秒 | 第 1、2、3 轮快速切换 | “先说出来，再说清楚，最后说自然。” |
| 18–24 秒 | 原话、建议、词汇 | “看建议，再讲一次。” |
| 24–30 秒 | 导出 Markdown | “练完收藏记录，下次继续。” |

**录制要求：**使用演示视频和演示记录；不要录入真实 API Key、邮箱、YouTube 账号信息或未脱敏的个人练习内容。不要暗示插件自动读取视频字幕或直接同步 Notion。
