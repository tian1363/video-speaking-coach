# Chrome 应用商店文案｜中文

## 名称

Video Speaking Coach｜看完就说

## 简短介绍

跟着简单流程练英语口语：看 YouTube、记关键词、复述三次、获得建议并保存记录。

## 详细介绍

想练英语口语，却不知道每天该怎么练？看视频时听懂了，轮到自己讲又说不出来？Video Speaking Coach 把“先输入，再主动输出”的练习方法做成可以直接跟着做的浏览器流程：看视频、提取关键词、自己复述、获得反馈、再次表达。

先看视频，记下关键词，然后用英语讲三次：

1. **先说出来**：只看自己记下的关键词，用语音把它们串成英文，不急着纠错。
2. **说清楚**：按主题、重点和例子组织表达。
3. **说自然**：独立重讲，加入自己的看法。

侧边栏会保存每轮原话和建议。每轮 AI 反馈依次分析问题、说明原因、给出完整英文重讲示例和下一轮练习动作，让你看到自己怎样从“先说出来”进步到“讲清楚”。你可以使用浏览器语音识别，再亲自检查和修改转写；也可以直接输入英文。查词提供免 Key 的基础翻译。若想要结合视频语境的解释、口语建议和问答，可自行配置 OpenAI 或阿里云百炼 API Key；相应服务可能收费。当前版本提供文字建议，暂不提供量化分数或发音评分。

无需预约课程：有空时打开视频和侧边栏，就能开始一轮练习。AI 教练由你选择服务商并自行管理密钥；如账号享有对应模型的免费额度，可按服务商规则使用，额度耗尽后可能产生费用。

完成三轮后，你可以重新练习并保留旧记录，或将这次练习下载为 Markdown 文件，收藏到 Notion 或 Obsidian。Notion 通过手动导入 Markdown 使用；当前版本不提供一键同步。

视频始终留在 YouTube。插件不会自动下载视频或读取完整字幕；AI 根据你提供的标题、关键词和复述给建议，因此你仍是练习的主角。

## 商店截图标题

1. 看完视频，直接在侧边栏开始练习
2. 记关键词，三轮复述逐步讲清楚
3. 每轮回看原话与建议
4. 完成后导出记录，继续下一次练习
5. 自选 AI 服务商；基础查词无需密钥
