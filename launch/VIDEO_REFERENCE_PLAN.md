# 视频内容对比：后续可选能力

## 为什么值得做

当前 AI 只知道视频标题、用户关键词和三轮复述，因此可以评价表达是否清楚，却无法可靠判断用户是否准确复述了视频。若有可信的视频口播文本，就能增加“关键观点是否覆盖、事实是否说反、哪些细节需要回看”的反馈。不要用逐字相似度给口语打分：用户的目标是用自己的英文解释理解，而不是背字幕。

## 推荐流程

1. 用户先看视频、记关键词，完成第一轮自由复述。首轮之前不展示字幕或 AI 摘要。
2. 第一轮之后，提供可选的“加入视频文字稿”入口。用户从 YouTube 界面自行复制字幕或粘贴自己的笔记，并可编辑、删除。界面明确说明这份文字的来源和是否完整。
3. AI 把文字稿作为参考，与用户原话对比，分开报告“表达问题”和“内容核对”：已覆盖的主旨、可能遗漏的重要信息、与文字稿冲突的说法。引用短片段供用户回看，不擅自断言不完整字幕之外的事实。
4. 用户再进行第二、三轮。完整重讲示例默认仍以用户已经理解和表达的内容为基础；若采用文字稿中的新事实，应清楚标明出处，让用户自行决定是否加入。

## 技术与发布边界

YouTube Data API 的 `captions.list` 只提供字幕轨道元数据，`captions.download` 需要视频编辑权限，不适合用来获取任意公开视频的字幕。当前插件不自动提取字幕，也不通过非官方接口抓取视频内容。优先实现用户主动粘贴文字稿和本地保存；如将来加入其他合法来源，逐一核对授权、覆盖率与失败提示。
